# Cinematic scene catalog

BsCode ships 20 muted, locally cached 1080p animated-art scenes for Cinematic
Mode. These are credited, artist-made CGI/Blender works—not AI-generated
images, photographic footage, or artificial pans across still pictures.

Only the selected scene is decoded and played. Posters are pre-rendered so the
settings gallery and first frame appear immediately, while `preload="none"`
keeps the other 19 videos dormant. Reduce Motion pauses scene playback.
