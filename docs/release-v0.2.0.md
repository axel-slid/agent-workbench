# BsCode 0.2.0

BsCode 0.2 is the visual-workspace release. It combines a reliable multi-agent
terminal with a full-screen cinematic wall, a faster Pixel tower, shared
workspace notes, and clearer status everywhere.

## Download

The macOS release is packaged for Apple Silicon (`arm64`) as
`BsCode-macOS-arm64.zip`.

## New

- 20 credited, artist-made 1080p CGI/Blender Cinematic backgrounds.
- True full-screen Cinematic Mode with four always-visible panes.
- `⌘K` shared command dock, Slack-style model/agent `@mentions`, Results
  access, next-scene control, and synchronized pane resizing.
- Optional Spotify-reactive atmosphere with strength, opacity, and fps
  settings.
- Workspace Notes with notes, todos, sketches, and agent-readable Markdown.
- Profile page with pixel avatar, display name, role, and focus.
- Local/remote storage usage in the status bar.
- Clickable calendar and proper macOS charging indicator.
- Command-palette workspace handoff copied as Markdown.

## Pixel Mode

- 20 pre-rendered tower preview PNGs—no hidden-floor cycling.
- Connected Empire State/Art Deco crown.
- More than 20 diverse room plans and palettes.
- Twelve distinct pet species.
- Clickable pixel RPG stat sheets with HP, energy, food, hobbies, traits, and
  talents.
- Agent clipboard items jump to the correct floor.
- Manual sunrise, day, sunset, and night cycle with local-time default.
- Clear terminal exit and a larger animated hot-coffee empty state.

## Agent workflow

- Enter reliably sends Zen/bullet follow-ups.
- Checklists allow only one active item and promote the next pending item.
- Current task and color-coded state appear in each agent.
- Workspace tabs show agent faces and optional live ETAs.
- Opened outputs are retained inside Files.
- A disconnected SSH workspace clears stale files and metrics.

## Interface

- Restored VS Code-style workspace address bar.
- Refined curved tabs, smaller plus control, aligned macOS traffic lights, and
  stronger light-mode contrast.
- Files/Workspaces pill switch.
- Home icon branding and immersive-mode guards.
- Searchable settings contain only actionable controls.

## Validation

- JavaScript syntax and packaging configuration checks.
- 42 feature regression checks.
- Screenshot-driven runtime checks for Home, local/SSH state, storage, Pixel
  Mode, Cinematic Mode, Settings, Notes, light/dark appearance, active/idle
  sessions, and launch behavior.
- Packaged Apple Silicon smoke test with native-binary architecture
  verification.

Artist and source credits for every bundled scene are in
